# 배너 이미지 등록
banner-data.js의 네 항목에서 image와 alt를 수정하세요.
예: { image: "./assets/banner/banner-01.jpg", alt: "브랜드 프로모션 배너" }
이미지는 이 폴더에 저장합니다. JPEG, PNG, WebP 등을 사용할 수 있습니다.
holdMs는 표시 시간, fadeMs는 전환 시간입니다(1000 = 1초).
frameRatio는 공통 표시 영역의 비율입니다. 이미지 전체가 보이도록 여백이 생길 수 있습니다.
배경과 노란색 클립 박스는 제공된 로컬 Figma 파일의 원본입니다.
