# 팝업 작업물 입력

1. 이미지 9개를 assets/popup/ 폴더에 넣으세요. 권장 이름: popup-01.jpg ~ popup-09.jpg.
2. 프로젝트 루트의 popup-data.js에서 해당 항목을 수정하세요.

```javascript
{
  image: "./assets/popup/popup-01.jpg",
  alt: "작업물의 시각적인 내용을 설명하는 문장",
  title: "작업물 제목",
  type: "Concept Design · Personal Project",
  tool: "Photoshop",
  size: "500 × 750 px",
  year: "2026",
  description: "첫 번째 설명 문단.\n두 번째 설명 문단."
}
```

- 목록 순서가 슬라이드 순서입니다. 이미지가 없거나 경로가 틀리면 번호 카드를 표시합니다.
- 이미지는 2:3 영역 안에 전체가 보이도록 표시합니다. 비율이 다르면 여백이 생깁니다.
- intervalMs: 7000은 7초마다 다음 이미지가 중앙에 도착한다는 뜻입니다.
- 자동 재생 중에는 연속 이동하며, 중앙에 도착한 이미지에 맞춰 설명이 전환됩니다.
- 마우스를 올리거나 키보드로 포커스하면 멈춥니다. 이전/다음·스와이프 조작 후에는 멈춘 상태를 유지하며 '자동 재생'으로 재개합니다.
- 운영체제의 동작 줄이기가 설정되어 있으면 자동 재생과 전환 효과가 기본적으로 꺼집니다.
- popup.css는 해당 섹션의 스타일, popup-slider.js는 슬라이드 동작입니다.
